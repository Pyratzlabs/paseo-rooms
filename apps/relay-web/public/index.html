One link. Shared context.

Rooms is deliberately narrow. It is a collaboration surface for the conversation, not remote control of someone else's environment.

01 / HOST

Start the work in Paseo.

An engineer runs the coding agent from their own workspace, with their own tools and approvals.

02 / SHARE

Create a scoped room.

The Share session extension mints one capability link for that conversation and nothing beyond it.

03 / COLLABORATE

Work through it together.

A teammate joins from any browser, follows the thread, replies in context and helps unblock the next decision.
